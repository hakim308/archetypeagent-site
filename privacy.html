Privacy information

Draft policy — not legal advice. This page describes the current prototype and must be reviewed and completed by the business owner before collecting personal information or launching paid services.

Current status: local sample mode runs in your browser. AI mode is inactive until a server endpoint is configured. Once enabled, the details submitted in the AI form (business name/type, audience, platform, tone, and content details) are sent to Archetype Agent’s Cloudflare Worker, which forwards the request to the OpenAI API to generate a draft. Do not enter sensitive or confidential information.

AI generation and service providers

When AI mode is enabled, the form details are transmitted to the Cloudflare Worker hosting the API endpoint and then to OpenAI for text generation. The Worker is configured to use the OpenAI Responses API with store=false and does not intentionally save prompts or generated drafts. This setting does not by itself guarantee zero retention by every provider; provider data-handling policies, account settings, and applicable terms govern their processing. Cloudflare and hosting providers may process technical request data, including security and operational logs.

Information and future features

The current product does not create user accounts, maintain saved customer workspaces, or process payments. Any future analytics, account, support, or payment features must be described here before activation, including the information collected, purposes, service providers, retention periods, user rights, and contact information.

Third-party services

The public website is hosted through GitHub Pages. The AI service, when activated, uses Cloudflare Workers and the OpenAI API. Each provider processes data under its own terms and privacy documentation.
